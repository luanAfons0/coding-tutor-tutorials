# The Project

This site is a **personal learning trail** — an ever-growing library of tutorials written while actually learning. Data structures in C is just the *first* topic; the idea is bigger than any single subject. Over time this will hold many courses, on whatever is worth digging into next.

## The idea

Most things you "learn" from a video or a blog post fade within a week. What *sticks* is what you **build yourself** and what you **come back to**. So this project runs on two rules:

- **Learn by building.** No copy-paste, no library doing the hard part. To understand a hash map, build a hash map.
- **Write it down, keep it forever.** Every topic becomes a tutorial that lives here, so knowledge compounds instead of evaporating.

## How to study this way

A few principles shape every tutorial — steal them for your own learning:

- **Start with the "why."** Not "here's the syntax" — "here's the problem this solves."
- **One idea, deep.** A tutorial that teaches three things well beats one that name-drops ten.
- **Anchor it in real code.** Concepts explained with actual code you've written, not abstract toy snippets.
- **Revisit on a schedule.** Spaced-repetition review pulls old topics back up before you forget them — weak spots get drilled often, solid ones fade into long-term review.

## How to organize yourself

Everything is plain Markdown, grouped so it stays navigable as it grows:

- **`courses/<subject>/`** — one folder per subject, each its own section in the sidebar. Pick a topic, give it a folder, fill it over time. (Data Structures & Algorithms is the first; more will join it.)
- **`extras/`** — supporting theory and references (like Big O notation) that aren't a project on their own but make the projects make sense.
- **A little metadata per tutorial** — its concepts, its reading order, when it was last reviewed — so the trail stays ordered and reviews know what's due.

The structure is deliberately boring: folders and Markdown files. That's the point — it's simple enough to keep up for years, and simple enough for anyone to copy.
