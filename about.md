# How am I

Hi — I'm a developer learning **how computers really work**, one data structure at a time.

## About me

I write **TypeScript** every day (with the occasional reluctant detour into C#). That means I've spent most of my time in comfortable, garbage-collected, high-level land — where memory "just happens." This project is me deliberately walking into the uncomfortable side: **C**, manual memory, pointers, `malloc`/`free`, and the bytes underneath everything.

I'm based in **Brazil** 🇧🇷, study *Análise e Desenvolvimento de Sistemas* at night, and work full-time during the day — so this is about an hour a day, carved out because I actually want to understand the machine, not just use it.

My goal isn't a certificate or a job title. It's simple: **become a better programmer by really learning how computers work.**

## About this project

This is my personal **learning trail** — a growing library of tutorials written *for me*, building on what I already know and using real code I've written. Each one teaches a single idea deeply, the way Julia Evans or Dan Abramov might explain it, and every tutorial sticks around so the knowledge compounds over time.

The plan is to build real things from scratch in C — no copy-paste, no libraries doing the hard part for me:

- **Foundations** — pointers, the heap, dynamic arrays, linked lists *(where I am now)*
- **A Redis-style in-memory store**
- **A tiny SQLite-style database**
- **A Game Boy emulator**

The **Extras** section holds the supporting theory (like Big O notation) — the complementary material that isn't a project on its own, but makes the projects make sense.

If you're reading this: welcome to my journey from *"I use computers"* to *"I understand computers."* 🚀
